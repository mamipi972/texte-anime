# Animated Text — a GIMP 3 plug-in

**[Version française → LISEZMOI.md](LISEZMOI.md)**

Create animated titles directly in GIMP 3: type your text, pick an effect from the gallery, and export an **MP4 video** (with sound effects), an **animated WebP** or an **animated GIF**.

![The plug-in dialog](docs/dialogue.png)

## Features

- **18 effects** in a gallery with animated previews (hover a thumbnail to play it).
- **Up to 3 screens** in a row, each with its own text and effect.
- **Timing like a motion-design tool**: animate by letter, word, line or whole block; choose the easing curve (smooth, overshoot, elastic, bounce) and the order (normal, reverse, from center, random).
- **Ready-made frame sizes**: square 1:1 (1080×1080), landscape 16:9 (1920×1080 or 1280×720), portrait 9:16 (1080×1920), vertical 4:5 (1080×1350), or custom.
- **Sound effects for MP4**: key clicks, whooshes, impacts, neon buzz… generated by the plug-in itself, so there are no third-party audio files and no licensing issues. They can be turned off.
- **Long text is handled**: lines wrap automatically and the text shrinks if needed to stay inside the frame.
- **Progress window** with a large progress bar, an estimate of the time left and a Cancel button. When done, a button opens the folder that contains the file.
- **Safe saving**: you are asked before an existing file is replaced, with an option to keep both.
- **Bilingual interface**: French if GIMP is in French, English otherwise.

A few notes on the more unusual effects:

- **Liquid**: when two consecutive screens both use *Liquid*, the first text melts and reforms into the second one (morphing).
- **Draw-on**: the plug-in follows the *outline* of each letter, like an animated cut-out. It does not imitate handwriting, which would require special single-stroke fonts.
- **Shatter**: this effect is noticeably slower to render than the others.

## Requirements

- **GIMP 3.2**. The plug-in was developed and tested with GIMP 3.2.4 on Windows 11. Other versions and other systems have not been tested.
- **ffmpeg**, for MP4 export only. WebP and GIF are exported by GIMP itself. See [Installing ffmpeg](#installing-ffmpeg) below.

## Installing ffmpeg

ffmpeg is a free tool that turns images into a video. The plug-in calls it during MP4 export, so it must be **installed and reachable from any folder**, which is what being "on the PATH" means.

### Windows — option 1: winget (recommended)

winget is the package manager built into Windows 10 and 11. It downloads ffmpeg, installs it and puts it on the PATH with a single command.

1. Open **PowerShell**: Start menu, type `powershell`, then press Enter. Administrator rights are not needed.
2. Type:
   ```powershell
   winget install Gyan.FFmpeg
   ```
3. The first time, winget may ask you to accept the terms of its catalog: type `Y` and press Enter.
4. winget downloads ffmpeg (the Windows build from gyan.dev, the one recommended by the official website), checks the file, installs it in your user folder and adds it to the PATH.
5. **Close PowerShell, open it again** and check:
   ```powershell
   ffmpeg -version
   ```
   If version information is displayed, ffmpeg is ready.
6. **Restart GIMP** if it was open: it only sees ffmpeg after a restart.

Useful commands later on:
```powershell
winget upgrade Gyan.FFmpeg     # update ffmpeg
winget uninstall Gyan.FFmpeg   # uninstall ffmpeg
```

> **"winget is not recognized…"**: install or update the **App Installer** app from the Microsoft Store, then try again. If winget is still unavailable (on a locked-down work PC, for example), use option 2.

### Windows — option 2: download from the website

The official site [ffmpeg.org](https://www.ffmpeg.org/download.html) only provides source code. For Windows, it links to ready-to-use builds, including those from **gyan.dev**.

1. Go to [gyan.dev/ffmpeg/builds](https://www.gyan.dev/ffmpeg/builds/). On ffmpeg.org, this is the "Windows builds from gyan.dev" link.
2. In the **release builds** section, download **`ffmpeg-release-essentials.zip`**. The *essentials* build is enough for the plug-in.
3. Unzip the archive. Rename the resulting folder (for example `ffmpeg-8.1-essentials_build`) to **`ffmpeg`** and move it to the root of your drive. You should end up with `C:\ffmpeg\bin\ffmpeg.exe`.
4. Add the `bin` folder to the PATH:
   1. Start menu, type `environment variables` and open **Edit environment variables for your account**.
   2. In the top list, select **Path** and click **Edit…**
   3. Click **New** and type `C:\ffmpeg\bin`.
   4. Click **OK** in every window.
5. Open a **new** PowerShell window and check with `ffmpeg -version`.
6. **Restart GIMP.**

To update, download the new archive and replace the contents of `C:\ffmpeg`. To uninstall, delete `C:\ffmpeg` and remove the `C:\ffmpeg\bin` line from the Path.

### macOS and Linux

- macOS (with [Homebrew](https://brew.sh)): `brew install ffmpeg`
- Linux: `sudo apt install ffmpeg` (or your distribution's equivalent)

### Troubleshooting

If the plug-in says ffmpeg cannot be found although it is installed:
- check that `ffmpeg -version` works in a **new** PowerShell window;
- close GIMP **completely**, then start it again;
- as a last resort, restart your computer so that Windows picks up the new PATH.

## Installation

1. Download this repository (green **Code** button → **Download ZIP**) and unzip it.
2. Copy the whole **`texte-anime`** folder, including its `apercus` subfolder, into your GIMP plug-ins folder:
   - Windows: `%APPDATA%\GIMP\3.2\plug-ins\`
   - Linux: `~/.config/GIMP/3.2/plug-ins/`
   - macOS: `~/Library/Application Support/GIMP/3.2/plug-ins/`
3. On Linux and macOS, make the script executable: `chmod +x texte-anime.py`
4. Restart GIMP.

The folder name must stay `texte-anime`, the same as the script name. GIMP requires this.

## Usage

1. **File → Create → Animation → Animated text…**
2. In the **Screen 1** tab, type your text. Press Enter to start a new line.
3. Click an effect in the gallery. The **Reveal / Motion / Mood / Special** tabs sort the effects.
4. Adjust the appearance (font, size, colors) and the output settings (frame size, file type, folder, file name).
5. Click **OK**. A progress window shows how far along the rendering is.

### Tips

- **Using only one or two screens**: leave the text of screen 2 or 3 empty, or untick **Include this screen**. Its text is kept for later. The tab then shows "— off".
- **Advanced timing settings** and **Custom size** open as floating panels, so the window never changes size.
- **File name**: just type a name, for example `intro`. The extension (.mp4, .webp, .gif) is added automatically.
- **Accent color**: used by three effects (the Wipe panel, the Neon glow and the Focus frame).
- **Hover** any setting to see a tooltip that explains it.

## Viewing the files and choosing a format

| Format | Open it with | Best for | Limits |
|---|---|---|---|
| **MP4** | Any video player (Windows Media Player, VLC…), any web browser, every video platform | Social media, YouTube, video editing, PowerPoint (insert as video) | Does not loop by itself in a web page or email; sent as an attachment, not shown inline in an email |
| **Animated WebP** | Any recent web browser (Chrome, Edge, Firefox, Safari on macOS Big Sur or later); viewers such as XnView MP or IrfanView (with plug-ins); GIMP (opens as layers: **Filters → Animation → Playback**) | Websites and documentation: light files, full colors | No sound. Windows File Explorer shows a still thumbnail. Not supported everywhere: desktop Outlook, some social networks, some versions of PowerPoint |
| **Animated GIF** | Everywhere: browsers, image viewers, email, PowerPoint, messaging apps | Email, PowerPoint, maximum compatibility | No sound. Only 256 colors: gradients, glows and blurs show visible bands (Neon, Blur in, Liquid). Much heavier files than WebP. Transparency is all-or-nothing |

The easiest way to check an animated WebP on Windows is to drag it into Edge or Chrome.

## Known limitations

- **WebP and GIF encoding** is a single call to GIMP. During that step the progress bar stays at 85 % and Cancel has no effect.
- **Render time** depends on the frame size and the effect: from a few seconds to about a minute in 1280×720. Blur in, Draw-on and Shatter are the slowest.
- **WebP and GIF have no sound.** Only MP4 can carry the sound effects.

## Working around GIMP 3.2 issues

These notes may help other plug-in authors:

- **Default colors are lost** when a color parameter is registered. The plug-in restores them when it runs.
- **Folder parameters crash GIMP on Windows**: a `GFile` folder parameter is saved with backslashes that GIMP cannot read back, which makes the next launch crash. The folder is stored as plain text instead.
- **Fonts may not be ready yet** when GIMP is started in console (batch) mode. The plug-in waits for them.
- **Filling an empty selection fills the whole layer.** Every rectangle is clipped to the image before it is drawn.
